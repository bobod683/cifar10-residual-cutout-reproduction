# 实验方案与学术诚信约束

## 研究问题

本实验回答两个预先确定的问题。

1. 在网络深度、卷积通道和训练超参数基本一致的条件下，残差捷径是否能改善 20 层卷积网络在 CIFAR 10 上的最终测试准确率与优化过程？
2. 在 ResNet 20 上加入固定长度为 16 的 Cutout 后，最终测试准确率是否进一步变化？

这是一项经典方法复现与受控扩展研究，不宣称提出了新的残差结构或新的 Cutout 算法。论文中的贡献应表述为可复现的受控比较、完整的多随机种子证据和对训练动态与类别差异的分析。

## 预注册式实验设计

在查看正式测试结果前固定以下设置：

- 数据集：CIFAR 10 官方训练集 50,000 张图像和测试集 10,000 张图像。
- 模型：Plain 20、ResNet 20、ResNet 20 加 Cutout。
- 随机种子：42、3407、2026。
- 正式训练次数：3 种方法乘 3 个种子，共 9 次。
- epoch：200。
- 优化器：SGD。
- 初始学习率：0.1。
- 动量：0.9。
- 权重衰减：0.0001。
- batch size：128；显存不足时可统一减小，但三种方法必须保持一致。
- 学习率计划：第 100 和第 150 个 epoch 结束后乘 0.1。
- 基础增强：四像素填充后的随机 32 像素裁剪和随机水平翻转。
- Cutout：在归一化图像上随机遮挡一个边长 16 的正方形区域，允许遮挡区域越过图像边界。
- 主要指标：最终测试 Top 1 准确率，报告三次运行的均值与样本标准差。
- 次要指标：最终测试交叉熵、测试错误率、逐类别准确率、训练损失、训练准确率、参数量和运行时间。
- 测试政策：每次训练结束后仅评估一次测试集，不依据测试集选择 epoch。

## 公平比较

Plain 20 与 ResNet 20 使用相同的卷积层数、通道配置、归一化、分类头和训练超参数。主要结构差异是 ResNet 20 的恒等或 Option A 参数无关捷径。ResNet 20 与 ResNet 20 加 Cutout 的网络结构和优化设置相同，差异只在训练输入是否应用 Cutout。

## 统计分析

每个方法报告三个固定种子的均值和标准差。相同种子的方法间差值作为配对差值报告。汇总程序同时计算精确双侧符号翻转检验，但三个配对样本的统计功效很低，因此论文不能仅凭显著性标签下结论；应同时讨论差值方向是否一致、效应大小、训练曲线和类别层面变化。

## 结果保全

每次运行必须保留：

- `metadata.json`：软件、硬件、命令、超参数和数据规模。
- `train_log.csv`：逐 epoch 的学习率、损失、准确率和耗时。
- `summary.json`：最终测试指标、混淆矩阵和逐类别准确率。
- `final_model.pt`：最终模型权重。
- `test_predictions.npz`：最终测试 logits 与真实标签。

打包脚本会把上述文件、汇总表、图片和实际运行源码写入压缩包，并生成每个文件的 SHA 256 摘要。任何缺失运行都会使汇总或打包失败。

## 禁止事项

- 禁止手工填写或修改准确率、损失、标准差、显著性结果和运行时间。
- 禁止删除表现不理想的种子后重新挑选种子。
- 禁止把冒烟测试、部分训练或中断训练当作正式结果。
- 禁止在不同方法之间使用不同 epoch、数据子集或学习率设置，却仍称为公平比较。
- 禁止把本复现实验表述为原创 ResNet 或原创 Cutout 方法。
- 禁止在 GitHub 仓库尚未创建或不能公开访问时填写虚构链接。

## 论文完成条件

只有在 9 次正式运行均通过完整性检查后，才撰写实验结果、结论和摘要中的数字。作者、单位、公开 GitHub 地址和权重发布地址由真实信息填写；没有收到的信息保留为待确认，不做猜测。
